Vim 中文资源

Vim 自带英文教程和帮助文档，中文化分两条路：跑自带教程时切语言，装社区维护的帮助文档包。

vimtutor 是 Vim 自带的 30 分钟交互式入门，环境变量切到中文 locale 就能直接读：

LANG=zh_CN.UTF-8 vimtutor

vimcdoc 是 yianwillis/vimcdoc 维护的中文帮助包，放进 pack/start 即随 Vim 加载，:help 直接出中文：

mkdir -p ~/.vim/pack/my/start
cd ~/.vim/pack/my/start
git clone https://github.com/yianwillis/vimcdoc.git

vim 终端粘贴自动缩进错乱用 :set paste

从浏览器 / 别的终端 app 粘贴一段已缩进的代码到终端 vim，每行缩进会层层叠加变成阶梯——因为终端 vim 收不到“这是粘贴”的信号，把每个字符当成键盘输入处理，于是每按一次回车就按上一行结尾的缩进起步。

粘贴前后切回来：

:set paste
" 粘贴...
:set nopaste

或者一行 toggle：:set invpaste。

GUI vim（gvim / MacVim）不需要——它能直接区分粘贴事件和键盘输入。Neovim 在多数现代终端也能自动识别 bracketed paste，可以不管。

vim 全选 / 全复制 / 全删全文

gg 跳首行、G 跳末行，前后一夹就是“全文”。组合公式 gg + 动作 + G：

ggvG   " 字符级全选（高亮）
ggVG   " 行级全选（整行高亮）
ggyG   " 全文复制到 0 号寄存器
ggdG   " 全文删除（等价于 dG，因为光标已在首行）

记住套路本身比记单条命令值——同样的夹击思想能拼出“从光标到末行替换”c、“格式化全文” gg=G 等任意操作。
